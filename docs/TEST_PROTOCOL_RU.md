# Протокол теста MirrorLab 0.3.1

## USB
1. Подключить iPhone/iPad кабелем, разблокировать и доверить Mac.
2. USB → Обновить USB-экраны → Запустить USB-экран.
3. Быстро проверить, что картинка и звук не регрессировали.
4. «Отдельное окно» должно оставаться живым и штатно раскрываться зелёной кнопкой macOS.
5. Никакие дополнительные USB-настройки в этом тесте менять не нужно.

## AirPlay
1. Запустить AirPlay.
2. На iPhone/iPad: Пункт управления → Повтор экрана → MirrorLab.
3. FairPlay должен пройти, а `Mirror TCP` — получить данные как в 0.2.4.
4. Главное отличие: `SETUP type=96` не должен бесконечно повторяться. В UI должны появиться `Audio UDP` data/control ports.
5. Если iPad начинает отправлять realtime audio, `Audio ingress` должен расти.
6. В `Video packets` должны начать расти H264 / codec / heartbeat counters. Поле `Codec` должно показать avcC profile/level, если codec packet пришёл.
7. Картинка AirPlay в 0.3.1 ещё не гарантируется: следующий технический слой — FairPlay key unwrap → decrypt H.264 → VideoToolbox → Metal.
8. Сохранить JSON-отчёт через 10–20 секунд после подключения и прислать его.
