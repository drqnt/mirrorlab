# MirrorLab 0.2.6

## AirPlay crash fix
- Исправлен вероятный runtime-crash 0.2.5 при первом входящем Mirror TCP потоке.
- Диагностический parser больше не сдвигает буфер по одному байту и не создаёт main-thread event на каждый rejected byte.
- Добавлен bounded resync scan (до 64 KiB за проход) и жёсткий лимит диагностического Mirror buffer 8 MiB.
- Неизвестный framing теперь безопасно агрегируется и логируется редко, сохраняя prefix для следующего анализа.
- Повторяющиеся type-96 SETUP во время старта UDP transport дедуплицируются: хранится только последний запрос/CSeq.
- USB media pipeline не изменён.

## Ожидание теста
- При выборе MirrorLab приложение не должно завершаться, даже если текущая гипотеза о 128-byte mirror header неверна.
- Если framing отличается, UI/отчёт покажет редкие `MIRROR framing ...` события вместо вылета.
