# MirrorLab 0.3.39

## Product UX pass

- Главное окно больше не содержит видеопредпросмотр: оно стало компактным окном настроек/выбора AirPlay или USB.
- Третий режим с companion-приложением удалён из пользовательского продукта и отчётов; к нему можно вернуться только если появится доказанное преимущество перед AirPlay/USB.
- Порты, protocol trace, crypto counters, native-rewrite checklist и live diagnostics убраны из основного UI.
- «Сохранить отчёт» перенесён в меню; живая диагностика доступна отдельным окном через меню «Диагностика».

## USB auto-connect

- При выборе USB MirrorLab сам включает discovery-loop, периодически ищет только подтверждённые iPhone/iPad muxed screen endpoints и автоматически запускает первый доступный источник.
- Кнопки «Обновить», «Запустить» и ручной выбор устройства больше не нужны для обычного сценария.
- При исчезновении кабеля preview закрывается; discovery остаётся активным и автоматически поднимает поток после следующего подключения.
- Media pipeline 0.3.37/0.3.38 не менялся: device-native compressed H.264/HEVC, VideoToolbox и direct CoreAudio сохранены.

## Preview window

- Отдельное окно открывается автоматически при первом живом кадре AirPlay или при запуске USB capture.
- Оно теперь является единственным primary renderer; это важно для AirPlay presentation queue после удаления встроенного preview.
- MirrorLab считывает фактические размеры текущего CVPixelBuffer и задаёт `NSWindow.contentAspectRatio`, поэтому обычный ресайз сохраняет aspect ratio источника без чёрных полос.
- При смене ориентации aspect ratio автоматически обновляется.
- Стандартный macOS fullscreen сохранён; в fullscreen возможны боковые/верхние поля, если aspect ratio дисплея отличается от устройства.

## Housekeeping

- Bootstrap banner больше не сообщает пользователю про исторические UxPlay/GStreamer/Homebrew зависимости.
- Виртуальная камера для OBS остаётся обязательной финальной функцией, но намеренно не входит в 0.3.39: сначала стабилизируется основной продукт и оба транспорта.
