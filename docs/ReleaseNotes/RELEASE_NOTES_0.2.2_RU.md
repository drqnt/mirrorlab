# MirrorLab 0.2.2

- AirPlay control listener больше не привязан к порту 7000: Network.framework выбирает свободный порт, который затем публикуется через Bonjour. Системный AirPlay Receiver macOS можно оставлять включённым.
- USB-режим теперь фиксирован на 60 FPS; переключатель 30/60 удалён.
- Добавлено отдельное чистое окно `MirrorLab Preview` для OBS/Discord.
- Добавлена кнопка открытия Preview сразу в полноэкранном режиме.
- Второе окно не удваивает счётчик render FPS в диагностике.
- USB audio pipeline намеренно не менялся: текущая низкая задержка и стабильность сохраняются.
